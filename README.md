# 霓虹数独 · Neon Sudoku

本分支基于用户上传的「霓虹数独 · Neon Sudoku.html」进行检查和修复。保留深色霓虹玻璃界面、星光背景、六档难度、候选笔记、三次提示、三次错误上限，以及通关彩带与烟花。`main` 保留原来的留白数独版本。

## 运行

`index.html` 包含全部样式和脚本，没有外部资源或生产依赖。推荐通过 HTTP 启动：

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

也可执行 `npm start`。部署时只需托管 `index.html`。仓库中的 `app.js`、`engine.js`、`styles.css` 是原版保留文件，霓虹版页面不加载它们；测试使用原版 `engine.js` 作为独立的唯一解校验器。

## 玩法与难度

| 难度 | 初始已知数字 |
| --- | ---: |
| 简单 | 42 |
| 中等 | 34 |
| 困难 | 27 |
| 专家 | 23 |
| 地狱 | 19 |
| 梦寐 | 17 |

点击空格，再用下方数字键或键盘 1–9 填入答案。N 切换候选笔记；再次输入同一候选数可取消标记；Delete / Backspace / 0 擦除；方向键移动，Tab 与 Enter 可用于键盘选格。

错误答案会即时抖动、弹出警告并增加错误计数，不会写入棋盘。累计三次错误即失败。每局有三次提示，优先填入选中的空格，否则随机填一格。正确填数会移除同行、同列、同宫对应的候选笔记。填满且全部正确后展示祝贺弹窗及粒子动画。

新游戏或切换难度会重新开局。本版本保留上传文件的规则，没有进度存档、撤销或暂停；刷新会开始新局。难度按线索稀疏程度分档，不是人类解题技巧评级；线索更少不保证每题都更难。19/17 线索题目来自同一个唯一解种子的合法同构变换，题目结构并非完全独立。

## 本次检查与修复

- 清理浏览器保存的本机路径、旧棋盘、键盘、计时和星光 DOM，避免初始显示错位和重复装饰；启动难度统一为简单。
- 用位掩码与最少候选数（MRV）求解替换逐格顺序回溯，避免稀疏题目长时间卡住页面；拒绝非法盘面。
- 随机挖洞超时或停滞时，改用唯一解种子补充线索，确保实际线索数与难度按钮一致。
- 为异步生成增加序号保护，旧任务不能覆盖最新游戏，出错时给出重试提示。
- 屏蔽 Ctrl / Cmd / Alt 组合快捷键的误输入，阻止游戏按键的默认行为，补充键盘选格、笔记状态和文字播报。
- 新局会停止上一局的烟花及动画任务；尊重系统减少动态效果设置。

## 验证

Node.js 18+：

```sh
npm test
```

`tests/neon.test.js` 覆盖六档共 30 个随机谜题的准确线索数、原地求解、独立引擎唯一性复核、超时兜底、非法盘面及导出文件清理。`tests/engine.test.js` 另外验证原版校验引擎。

可选浏览器回归需安装 Playwright 并提供 Chromium。先启动上述 HTTP 服务，然后：

```sh
node tests/browser.cjs
```

默认使用 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定其他路径。测试覆盖笔记、擦除、错误警告、提示额度、三次错误失败、重新挑战、全部难度、并发生成、17 线索完整通关、动画清理，以及 390/320 像素手机布局。截图保存在 `/tmp/neon-*.png`。Playwright 仅是测试工具，不是游戏运行依赖。
